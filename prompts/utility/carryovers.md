# Analyze Year-Over-Year Carryovers

## Task Overview

Analyze action items across two consecutive years to identify continuity and changes in program
priorities.

## Input Data Structure

- **Column A:** Program name
- **Columns B-F:** Action plan data for the previous year (5 columns)
- **Columns G-K:** Action plan data for the current year (5 columns)
- **Note:** Each program has 3 to 5 action items per year

## Objective

Examine items for each year and analyze the extent to which they are similar.

## Expected Output

Create an Excel sheet with the following structure:

| Column | Content                              |
| ------ | ------------------------------------ |
| A      | Program name                         |
| B      | Percentage overlap for the two years |
| C      | Brief interpretation                 |

The percentage should reflect how much of the current year's action items carry over or align with
the previous year's items.
