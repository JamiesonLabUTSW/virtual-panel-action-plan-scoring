# Data Analysis: Reliability Metrics

## Overview

Analyze inter-rater reliability using appropriate statistical measures based on your data structure.

## Data Structure

- **Format:** Excel spreadsheet with structured rating data
- **Columns:** Rater identifiers in header row
- **Rows:** Program names in first column, with corresponding ratings

## Available Metrics

### For Multi-Rater Scenarios

- **ICC(2,1)** – Estimated agreement for a process with only one rater
- **ICC(2,3)** – Estimated agreement for a process with three raters

### For Two-Rater Scenarios

- **Cohen's Kappa** – Measures inter-rater agreement between two raters
- **Gwet's AC1** – Alternative agreement metric, more robust to marginal distributions

## Request Template

When providing data, please specify:

1. The number of raters
2. The rating scale or data type
3. Which reliability metric(s) you need calculated
4. Any specific requirements for interpreting results
