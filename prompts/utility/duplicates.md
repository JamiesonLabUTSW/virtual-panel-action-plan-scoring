# Duplicate Detection: Similar Action Items

## Objective

Identify programs with highly similar action plans and flag potential duplicates or redundant
planning.

## Input Data Structure

- **Column A:** Program name
- **Columns B-F:** Action plan data (5 columns per program)
- **Count:** 3 to 5 action items per program

## Analysis Tasks

1. **Compare programs** to identify those with highly similar action plans
2. **Flag similarities** with clear reasoning for each match
3. **Provide summary** of duplicate or similar patterns discovered

## Expected Output

### Summary Format

- Written narrative identifying groups of similar programs
- Explanation of what makes each group similar
- Confidence level for each similarity assessment
- Recommendations for consolidation or differentiation if applicable

### Detailed Table (Optional)

If a detailed table is requested, include:

| Program 1 | Program 2 | Similarity Score | Key Similar Elements | Confidence |
| --------- | --------- | ---------------- | -------------------- | ---------- |
|           |           |                  |                      |            |

## Similarity Criteria

Consider similarity across:

- Overall strategy and goals
- Specific action items and objectives
- Timeline and measurement approaches
- Resource allocation and team composition
